# Fin-Spectra — Phase 1 Code Audit (REALITY_AUDIT.md)

| Component | Current Implementation | Mock/Fake? | What Must Replace It |
| --- | --- | --- | --- |
| **Data Schema (`app/models/schema.py`)** | Basic `Customer`, `Account`, `Transaction`, `Alert`, `InvestigationCase` models lacking KYC income, onboarding dates, currency, channel, IP, device context, and full investigation metrics. | Partial | Full SQLAlchemy persistence layer with `declared_income`, `onboarding_date`, `address`, `country`, `kyc_status`, `balance`, `currency`, `channel`, `description`, `device_id`, `ip_address`, `triggered_rules`, `initial_risk`, and investigation state history. |
| **Data Seeder (`seed_db.py`)** | Pure random generation (`random.choice`, `random.uniform`) without structured AML topologies. | Yes (Random placeholder) | Deterministic synthetic dataset generator (`python -m app.data.seed`) creating realistic test cases with stable IDs: Normal customers, Structuring, Fan-in, Fan-out, Rapid Pass-through, Circular Flow, Mule/KYC mismatch. |
| **Evidence Retrieval Agent (`app/agents/nodes/evidence_retrieval.py`)** | Queries DB, but if records are missing, falls back to generating fake transactions (`random.uniform`), fake account IDs (`ACCT-2000-A`), fake devices, and fake beneficiaries. | Yes (Fake fallback) | Pure database-backed evidence retrieval agent with zero fake fallbacks. Returns structured evidence with explicit source table, source record ID, timestamp, and entity context. |
| **KYC Investigation Agent (`app/agents/nodes/kyc_verifier.py`)** | Hard-coded occupation string comparisons (`Student`/`Unemployed` > $5k). | Yes (Heuristic mock) | Quantitative KYC verification engine comparing `declared_income` vs observed volume (`income_activity_ratio`), account age, account type, risk profile, with supporting source record citations. |
| **Behavior Analysis Agent (`app/agents/nodes/behavior_analyzer.py`)** | Calculates Z-score on ledger items, but relies on fake transactions added by evidence agent and arbitrary variance floor. | Partial | Full statistical baseline calculation (mean, median, stddev, transaction count, inflow/outflow volumes, velocity surge, pass-through ratio) derived exclusively from real DB transactions with proper zero-variance handling. |
| **Transaction Typology Detection (`app/agents/nodes/typology_classifier.py`)** | Relies purely on LLM prompt generation from text summary. | Partial (LLM-only) | Deterministic detection engine for Structuring, Fan-In, Fan-Out, Rapid Pass-Through, and Circular Flow operating directly on database transactions, validated by LLM reasoning. |
| **Graph Analysis Agent (`app/agents/nodes/graph_analyst.py`)** | Basic length counts on arrays mapped to legacy flag names (`tx_per_account`, `self_transfer_detected`). No true network graph built. | Yes (Simulated graph metrics) | Real NetworkX graph analysis engine building directed multi-graphs (Nodes = accounts, Edges = transactions with amount, timestamp, type). Computes degree, centrality, fan-in/out ratios, 2-hop neighbors, cycles, and intermediary nodes. |
| **Investigation Planner (`app/agents/nodes/investigation_planner.py` / `task_planner.py`)** | Fixed static node execution sequence. | Partial | Dynamic tool-based LangGraph planner selecting tools (`get_customer`, `get_account`, `get_transactions`, `analyze_behavior`, `calculate_typology`, `build_transaction_graph`, `analyze_graph`, `get_kyc_profile`, `get_regulatory_guidance`) based on objective and evidence. |
| **Plan Checker (`app/agents/nodes/plan_checker.py`)** | Simple status string check. | Partial | Evidence-aware plan checker verifying completed tasks, required evidence keys, and source record citations before allowing progression to risk engine. |
| **Risk Scoring Engine (`app/agents/nodes/scoring_node.py`)** | Arbitrary weighted sum formula with coarse sub-score caps. | Partial | Transparent, reproducible risk engine where every risk factor (Behavior Z-score, KYC mismatch, Structuring, Fan-in/out, Rapid pass-through, Circular flow, High-risk network) has explicit factor value, source, weight, and contribution. |
| **Regulatory Knowledge Agent** | None (Generic LLM memory used in prompts). | Yes (Uncontrolled) | Controlled Regulatory Knowledge tool/agent querying official AML guidance (FATF, FinCEN, FIU) returning exact title, section reference, and retrieval date. |
| **Case Assembler & SAR (`app/agents/nodes/case_assembler.py`)** | Summarizes payload via LLM. | Partial | Grounded SAR dossier generator with full evidence provenance lineage (Finding → Agent → Calculation/Tool → DB Query → Source Record IDs). |
| **Real vs. Demo Mode** | Hard-coded fallbacks everywhere without explicit mode separation. | Yes | Strict `DEMO_MODE=true|false` configuration. When `DEMO_MODE=false`, system strictly rejects fabricated evidence or synthetic fallbacks. |
